3. Единый корпоративный логотип

    Создан единый основной asset:

      ─ text
      app/assets/images/company-logo.png

    Текущий пользовательский логотип уже скопирован туда. В дальнейшем достаточно заменять только этот файл.

    Он используется для:

    • desktop header;
    • mobile header;
    • светлой и тёмной темы;
    • high-contrast темы;
    • стандартных цветовых тем;
    • BIM-темы;
    • PDF-экспорта;
    • ранее сохранённых встроенных тем, которые всё ещё ссылаются на старые OpenProject assets.

    Центральный путь определён здесь:

      ─ text
      lib/open_project/custom_styles/design.rb

    Требования к своему логотипу

    Рекомендуемый формат:

      ─ text
      PNG с прозрачным фоном
      700 × 150 px

    Рекомендуется:

    • сохранять пропорцию примерно 14:3;
    • оставить небольшие прозрачные поля по краям;
    • использовать вариант, читаемый как на светлом, так и на тёмном фоне;
    • не менять имя company-logo.png.

    После замены файла нужно пересобрать assets или frontend, перезапустить приложение и очистить кэш браузера.
